# ITC Avant Garde Gothic (1970)

**Essence:** A magazine logo grown into a typeface — perfect circles packed so tightly that letters touch, lock and fuse into ligatures, turning words into emblems.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Logo-first typeface | Lubalin designed the *Avant Garde* magazine masthead (late 1960s); ITC released the full face in 1970 as its first typeface (with Souvenir). The type was born as identity, not as text. | Design the wordmark first, then extract a display alphabet from its rules (stroke, curve radius, joining logic). Use that display alphabet only for headlines ≥ 40px; set every UI string in a separate text face. |
| G2 · Ligatures as interlocking shapes | The original came with alternate characters and ligatures (slanted A, interlocking CA, TT, LA) that let letters share strokes. ITC's OpenType release restored 33 of them. | Use discretionary ligatures (`dlig`) or custom joined glyphs only in the wordmark and one hero line per page; never in buttons, nav or body. One locked pair per word, maximum. |
| G3 · Tight, touching fit | Headlines were set so letters kiss — the "Lubalin look" of 1970s ad typography. | For display only: tracking −3% to −6% at ≥ 64px, kerning checked pair by pair, line-height 0.9–1.0. Below 32px restore default spacing; touching letters destroy legibility at text sizes. |
| G4 · Huge x-height, perfect round | The circular o, a and e with a very large x-height give massive presence per character. | A large-x-height geometric reads loud at modest sizes — a 32px headline can carry a 48px voice, useful on small mobile screens; drop one heading level compared with a Futura-style face. |

## Visual facts

- **Classification:** geometric sans (display-oriented).
- **Designer · year · foundry:** Herb Lubalin (concept, from his *Avant Garde* magazine logo) and Tom Carnase (full character set, ligatures, weights), ITC, New York, 1970. Condensed by Ed Benguiat (1974); optically corrected obliques by André Gürtler, Erich Gschwind and Christian Mengelt (1977).
- **Digital versions & licences:** ITC Avant Garde Gothic (ITC/Monotype); the Pro OpenType version restores the alternates and ligatures that early digitisations dropped. Commercial. A standard PostScript core font, which is why metric twins exist.
- **Proportions:** very large x-height, short ascenders/descenders, near-perfect circles, single-storey a, low contrast, wide counters; obliques rather than italics.
- **Free / open alternatives (keep the gene):** TeX Gyre Adventor (GUST licence, based on URW Gothic L) and URW Gothic (URW base 35) — Avant Garde metrics and skeleton; draw your own ligatures for the logo gene.

## Attitude

Lubalin treated letters as raw material for expression: type could be squeezed, joined and rearranged until a word became a picture. Avant Garde is that attitude productised — powerful in the hands of a typographer, crude when used naively.

## Using it today

- **Signals:** 1970s magazines and ads, disco-era branding, sportswear logos modelled on it (Adidas's older wordmark is often described as Avant Garde-like), retro packaging. Saturation: medium; reads strongly "1970s" unless reworked.
- **Robotic ↔ humane:** 3/10 — compass circles and mechanical construction; the human element is the designer's hand in spacing and ligatures, not the letterforms.
- **UI fitness:** display and logos only. Body text fatigues fast (similar circular letters, tight default spacing in some cuts); UI labels ≥ 14px if at all. Latin-focused; check extended Latin and Cyrillic per vendor.
- **Pairs with:** a quiet neo-grotesque or humanist text face (Helvetica, Source Sans 3) below the headline; Didot or Bodoni for fashion-editorial tension; Courier Prime for retro captions.

## Blends

- **Amplifies:** `herb-lubalin`, `push-pin-studios` — expressive American typography of the 1960s–70s.
- **Productive tension with:** `swiss-international` — one Avant Garde ligature mark inside a disciplined grid reads as wit, not nostalgia.
- **Clashes with:** `helvetica` set as neutral body next to it in the same weight — both lose; give each a clear role.

## Don't copy

The *Avant Garde* magazine masthead; ITC's ligature drawings; the Adidas wordmark or other famous logos built on the face.
