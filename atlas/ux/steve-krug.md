# Steve Krug

**Essence:** Don't make people think: every page should be obvious at a glance, because users scan, take the first reasonable option and muddle through — design for how people really behave, and check it by watching a few of them.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Self-evident before self-explanatory | A page should be understood without effort; if that fails, at least with a moment's thought | No clever or branded names for standard things ("Jobs", not "Opportunity Hub"); anything clickable looks clickable; question marks in a user's head count as bugs |
| G2 · Billboards, not novels | People scan and satisfice, so design like a billboard seen at speed | Visual hierarchy where importance = size + weight + position; pages divided into clearly bounded areas; related items nested visibly; noise (badges, banners, ads) cut ruthlessly |
| G3 · Omit needless words | Most web copy is "happy talk" and unread instructions; cut half, then half of what remains | No welcome paragraphs; instructions only inline at the point of need, one line long; headings carry the message so the page reads by headings alone |
| G4 · The trunk test | Dropped onto any page, a user should know what site this is, what page, the main sections, where they are, and how to search | Every page: site identity top-left, page name matching the link clicked, a "you are here" state in navigation, search in a predictable spot |
| G5 · Design for muddling through | People guess and backtrack instead of reading how things work | Back always works and preserves state; breadcrumbs; no dead ends (every empty or error state offers a way forward); multiple paths to common tasks |
| G6 · Guard the reservoir of goodwill | Each annoyance drains goodwill; helpful acts refill it | Show what people came for (prices, contact, delivery times) without hunting; accept any input format; explain why you ask for data; apologise plainly when things fail |

## Visual facts

- **Color:** conventional and functional — clear link colour, high-contrast text, colour used to separate page areas.
- **Type:** plain sans, large clear page titles → Source Sans 3, Public Sans.
- **Form:** tabs, obvious buttons, bounded areas; nothing that hides interactivity.
- **Composition:** conventional placements (logo, navigation, search) so attention goes to content; generous headings.

## Attitude

Krug's *Don't Make Me Think* (2000; revised 2014) made usability readable and funny, and *Rocket Surgery Made Easy* (2010) argued that any team can run small do-it-yourself tests: three users, one morning a month, the whole team watching, fix the worst problems first. He calls arguments about what "users like" religious debates that only testing can settle.

## Blends

- **Amplifies:** `jakob-nielsen`, `don-norman`, `gestalt-principles` — convention, signifiers and visual grouping.
- **Productive tension with:** `bret-victor` — invented media need explaining; Krug's discipline makes new interaction forms legible at first glance.
- **Clashes with:** `david-carson` — expressive illegibility and self-evidence cannot share the same working surface.
