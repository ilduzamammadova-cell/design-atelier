# Alan Kay

**Essence:** The computer is not an appliance but a new medium — a metamedium that anyone, children first, should be able to read, write and reshape, learning by doing before abstracting.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Doing → images → symbols | Borrowing Bruner's three mentalities, Kay designed for action first, picture second, abstraction last | Onboarding starts with manipulating a real object (drag a sample, scrub a value), then reveals the visual model, and only then exposes settings, syntax or formulas |
| G2 · A medium, not an app | Smalltalk let users inspect and change any object, so tools could be made by the people using them | Every object has an inspector and a "view source"; user-built templates, macros and components are first-class citizens beside built-in ones |
| G3 · Low floor, high ceiling | A child should start in seconds; an expert should never hit the roof | First meaningful creation in under 30 seconds with no reading; the same surface opens into scripting or formulas without switching products |
| G4 · Uniform handles on everything | In the Smalltalk tradition every thing is an object; later Squeak/Etoys gave any object the same halo of handles | Any selected element — text, image, shape, data row — shows the same handle set: move, resize, duplicate, inspect, delete, in the same positions |
| G5 · Many contexts at once | Overlapping windows at PARC let several activities stay visible and switchable | Side-by-side panes, resizable splits and tabs that keep state; nothing full-screen-modal unless the task truly requires it |
| G6 · Design from the future backwards | Kay sketched the Dynabook (1972) years ahead of hardware, then built "interim" versions | Write the ten-year ideal of the product as a one-page scenario; each release ships one slice of it and is judged against that scenario |

## Visual facts

- **Color:** Smalltalk-80 was black-on-white bitmaps; Etoys later went bright and toy-like. Two modern readings: paper-white #FAFAF7 with ink #1A1A1A, or a saturated learning palette with tile colours per object type.
- **Type:** bitmap UI fonts → Atkinson Hyperlegible or IBM Plex Sans for legibility; a pixel face only as accent.
- **Form:** overlapping rectangular windows with title tabs, pop-up menus at the pointer, draggable tiles.
- **Composition:** a desktop of simultaneous workspaces rather than one screen at a time.

## Attitude

Kay saw personal computing as a literacy, like reading and writing, whose purpose was to change how people think — especially children, influenced by Seymour Papert's Logo work and Piaget. Ease of use was never the goal by itself; growth of the user was. He has often criticised the industry for shipping the surface of PARC's ideas while losing the authoring.

## Blends

- **Amplifies:** `bret-victor`, `douglas-engelbart`, `ben-shneiderman` — direct, explorable, augmenting media.
- **Productive tension with:** `dieter-rams` — Rams's restraint on the surface with Kay's open-ended malleability underneath gives calm tools that can still be rebuilt by their users.
- **Clashes with:** `persuasive-technology` — a medium for authorship and a funnel for consumption pull in opposite directions.

## Don't copy

The 1972 Dynabook concept drawing, Smalltalk's balloon logo, the Squeak mouse mascot and Etoys characters. Take the authoring principle, not the period look.
