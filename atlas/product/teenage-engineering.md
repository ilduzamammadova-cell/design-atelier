# Teenage Engineering

**Essence:** Hardware as a graphic instrument, calculator-precise objects with playful constraints, colour-coded controls and screens drawn like toys.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Colour-coded encoders mapped to screen | The OP-1 synthesizer (introduced 2010) has four rotary encoders, blue, green, white, orange, and every on-screen parameter is drawn in the colour of the knob that controls it. | **Product:** each physical control has one colour, repeated on the display. **UI:** semantic colour-to-control binding: up to four control colours, each tied to an input (e.g. arrow keys, scroll, two hotkeys); every adjustable value on screen is tinted with its control colour, so users know which input changes what. |
| G2 · Pictures instead of menus | OP-1 screens replace parameter lists with small animated scenes and diagrams that visualise sound. | **Product:** screen graphics explain the mechanism. **UI:** represent settings as live, playful diagrams (a waveform you reshape, a dial you see turning) instead of forms; text labels only as secondary support. |
| G3 · Exposed board as enclosure | The Pocket Operators (2015, with Cheap Monday) are bare circuit boards with a calculator-style LCD and a printed graphic layer, no case, only a folding stand. | **Product:** remove the enclosure; print the interface onto the structure. **UI:** "naked" UI that shows its grid, labels and system values directly, monospace parameter readouts, visible grid lines, raw states, styled through precision rather than surfaces. |
| G4 · Productive constraint | Limited tracks, short sample time and fixed sequencer steps push creativity; constraints are part of the instrument's character. | **Product:** fixed limits that become a style. **UI:** deliberately bounded tools, 4 tracks, 16 steps, 8 colours, communicated visually (16 squares, not an infinite timeline); limits shown as a feature, not an upsell. |
| G5 · One tactile signature | The Playdate handheld (with Panic, announced 2019) has a crank credited to TE; the Rabbit r1 (2024) uses a scroll wheel. One unusual physical control gives each product an identity. | **Product:** one surprising physical input per product. **UI:** one signature interaction (a crank-like rotary scrub, a long-press radial) that only this product has, used for one core action. |
| G6 · Flat-pack and kit thinking | Computer-1 (2021) is a folded sheet-metal PC case; IKEA Frekvens (2020) was a modular party audio-light kit. | **Product:** fold, slot and assemble from flat parts. **UI:** components that ship as kits, composable blocks with visible "fold lines" (dividers) and snap-together layouts users can reconfigure. |

## Visual facts

- **Color:** aluminium (#C9CBCD), white (#F4F4F2), black (#111111), encoder blue (#2E6CF6), green (#2BB673), orange (#FF6A13), signal red; Rabbit r1 orange (#FF4F00).
- **Type:** custom TE pixel and technical lettering, lowercase labels, numbered parts. Free equivalents: JetBrains Mono, IBM Plex Mono, Silkscreen (pixel), Archivo for labels.
- **Form:** milled aluminium plates, round encoders, square keys, exposed PCB, folded sheet metal, tiny OLED/LCD screens.
- **Composition:** strict grid of controls, numbered and labelled like a technical drawing; screens with dense playful graphics.

## Attitude

TE designs products that invite play and creativity, treating tools as toys and toys as serious tools. Founded in 2005 by Jesper Kouthoofd, David Eriksson, Jens Rudberg and David Möllerstedt, the studio blends engineering, graphic design and humour, and increasingly designs for others (Nothing, Panic, Rabbit, IKEA).

## Blends

- **Amplifies:** `dieter-rams`, `olivetti`, `charles-and-ray-eames`.
- **Productive tension with:** `kenya-hara`, TE's dense playful graphics with Hara's emptiness give instrument UIs that are mostly silent with tiny precise playgrounds.
- **Clashes with:** `streamline-moderne`, hiding mechanisms under styled shells contradicts TE's exposed, labelled logic.

## Don't copy

The OP-1 and OP-1 field layouts, Pocket Operator board graphics, OP-Z, OB-4, EP-133, Computer-1 forms and TE's screen illustrations and typography. Take control-colour binding and productive constraint.
