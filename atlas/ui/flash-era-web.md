# Flash-Era Web

**Essence:** The browser as an instrument, navigation that wobbles, springs and sings, compositions generated by code, and pixel type as fine as circuitry.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Navigation as a toy | Yugo Nakamura's elastic menus and physics experiments made interface elements respond to the pointer like springs and magnets, fun before anything was clicked. | Menu items react to pointer proximity with spring physics (e.g. stiffness 170, damping 26): they lean, attract or repel within ±12 px. Interaction itself becomes the brand moment. |
| G2 · Generative composition | Joshua Davis (praystation.com, 1998; once-upon-a-forest, 1999) wrote rules that composed artwork randomly within constraints, so each view was new. | Hero or background generated at load from a seeded ruleset (shapes, rotations, palette picks within limits); new on each visit; expose a "reseed" control and allow saving a favourite seed. |
| G3 · Pixel type and HUD micro-labels | Tiny non-antialiased pixel fonts (Silkscreen, 04b and peers) labelled everything with coordinates, version numbers and data tags. | Secondary labels in 8 px pixel caps with +1 px tracking; decorative data tags (`x:120 y:44`, `v3.1`) and 1 px hairline frames; primary reading text stays in a legible face. |
| G4 · Waiting as theatre | Preloaders with precise percentages and short title sequences turned load time into a show (and spawned the "skip intro" button). | Treat loading as a designed moment: numeric progress, a ≤3 s title sequence that plays once, and an always-visible Skip. |
| G5 · The fixed cinematic stage | Sites lived on a centred fixed-size canvas with sci-fi chrome, corner brackets, glows, metallic panels (2Advanced Studios epitomised it). | A fixed-aspect stage that scales as a whole unit; frame it with corner brackets and scanline texture; hover adds a 6 px outer glow in the accent colour. |
| G6 · Sound in the interface | Rollover ticks and ambient loops were part of the experience. | Hover/click micro-sounds (≤40 ms) and an optional ambient loop with a visible mute switch; default muted in modern contexts. |

## Visual facts

- **Color:** gunmetal and charcoal (`#1A1D21`), electric orange `#FF6A00`, cyan `#00D2FF`, acid lime; or Davis's bright flat vector palettes on white.
- **Type:** pixel fonts (Silkscreen by Jason Kottke, 04b by Yuji Oshimoto, Craig Kroeger's Miniml); extended techno sans (Eurostile family). Free: **Silkscreen**, **Michroma**, **Orbitron**, **Barlow**.
- **Form:** vector shapes, hairlines, radial glows, gradients, layered transparency, motion trails.
- **Composition:** full-screen or fixed stage, centred; panels slide and expand; content revealed in sequences rather than scrolled.

## Attitude

Flash (FutureSplash, acquired by Macromedia in 1996) let designers write code, and a generation used it as an art medium: portfolio sites were laboratories, judged by peers as much as clients. Experience outranked information. Its end, mobile, accessibility, Steve Jobs's "Thoughts on Flash" (2010), end-of-life in 2020, is part of the lesson: keep the spirit, ship it on open standards.

## Blends

- **Amplifies:** `demoscene-and-tracker-ui`, `game-ui`, `designers-republic`, techno ornament and play.
- **Productive tension with:** `editorial-web`, theatrical motion disciplined by reading needs becomes art-directed scrollytelling.
- **Clashes with:** `dieter-rams`, interaction-as-toy contradicts "as little design as possible"; the blend tends to neuter both.

## Don't copy

- Specific sites and experiments (praystation, once-upon-a-forest, Nakamura's yugop.com pieces, 2Advanced versions), studio logos, Hillman Curtis's films and site designs.

## Study

- Web Design Museum (webdesignmuseum.org), Flash-era site captures, including 2Advanced Studios (1999).
- Hillman Curtis, *Flash Web Design: The Art of Motion Graphics* (New Riders, 2000).
- *New Masters of Flash* (friends of ED, 2000); Joshua Davis's later generative work (HYPE framework).
- Flashpoint Archive and the Ruffle emulator for running preserved Flash work.
