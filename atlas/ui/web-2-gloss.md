# Web 2.0 Gloss

**Essence:** The friendly startup web of the mid-2000s — glossy pills, wet-floor reflections, beta badges and giant sign-up fields promising that the internet was now social.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Glossy pill CTA | Calls to action became rounded capsules with a gradient and a hard-edged highlight across the upper half, borrowed from Aqua. | CTA = full-radius pill, two-stop gradient (light→mid of brand hue), top-half overlay `linear-gradient(rgba(255,255,255,.35) 50%, transparent 50%)`, 1 px darker border. One per view. |
| G2 · Wet-floor reflection | Logos and product shots stood on an imaginary glossy surface, mirrored and fading out. | Product image mirrored below itself at 30% opacity fading to 0 over 40% of its height; reserve for one hero object. |
| G3 · Badge and starburst | Rotated "beta" stickers and star-shaped flashes announced novelty — software as perpetual beta. | One rotated (−12°) circular or star badge per page for the single most important announcement; never two. |
| G4 · Big type, big fields | Huge friendly headlines, lowercase rounded logos and oversized input fields made sign-up feel effortless. | Hero copy 32–48 px; a single large input (≥52 px tall) fused to its button; lowercase rounded wordmark. Forms reduced to one field when possible. |
| G5 · Fresh mid-tone palette and stripes | Lime greens, sky blues, oranges and pinks, often over soft diagonal stripes or subtle gradients. | One saturated mid-tone brand colour plus white; header band with 45° stripes at 4% opacity; light gradient (top lighter by 8%) on panels. |
| G6 · Data that sizes itself | Tag clouds scaled words by popularity; vote and share counters sat beside every item. | Let frequency drive type size (font-size ∝ log count, 12–32 px); show counts next to social actions as part of the control. |

## Visual facts

- **Color:** lime `#8DC63F`, sky `#3BB7EA`, orange `#FF7F00`, hot pink `#FF0084`, on white or very light grey; soft grey gradients for panels.
- **Type:** Lucida Grande, Verdana, Arial Rounded, VAG Rounded, Georgia for blog text. Free: **Nunito**, **Varela Round**, **Open Sans**, **Georgia**-like **Gelasio**.
- **Form:** rounded corners (built with image "sliding doors" before CSS radius), gradients, gloss, reflections, drop shadows, cute pictogram icons.
- **Composition:** centred fixed-width layouts (~960 px), big hero with screenshot, three-column feature rows with icons.

## Attitude

"Web 2.0" (popularised by O'Reilly Media's 2004 conference) meant the web as a platform for participation: users make the content, software is never finished. The visual language advertised approachability and momentum. Under the gloss sits a useful belief — reduce friction to the first action — that survives without the shine.

## Blends

- **Amplifies:** `mac-os-x-aqua`, `ios-skeuomorphism` — shared glossy materialism.
- **Productive tension with:** `brutalist-web` — gloss placed deliberately on raw structure makes knowing, ironic contrast.
- **Clashes with:** `metro-design-language` — chrome-free typographic flatness and glossy chrome cancel each other out.

## Don't copy

- The logos and wordmarks of period startups (Flickr, Digg, del.icio.us and others), specific landing pages, stock icon sets of the era used wholesale.
