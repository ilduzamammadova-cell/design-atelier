# Palm OS

**Essence:** A 160×160-pixel pocket tool designed by subtraction, a few taps, no waiting, nothing that can't justify its pixels.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Design for the frequent 20% | Palm's own "Zen of Palm" guidance: build for the few things people do most often, many times a day, and push everything else down. | Each screen shows only the 3 most frequent tasks for its context; secondary features go to one menu. Write the frequency list before the feature list. |
| G2 · Count the taps | Speed was measured in taps and seconds; a calendar entry or phone lookup had to be near-instant. | Set a tap budget for core tasks (≤3) and track it like a performance metric; any redesign that adds a tap to a core task must remove one elsewhere. |
| G3 · No save, no boot, no state loss | Devices were instant-on; data persisted on every change; apps reopened where you left them. | No Save button; edits persist on change; reopening restores exact scroll position and selection. Remove "Are you sure?" dialogs in favour of undo. |
| G4 · Fixed doors to the core apps | Four hardware buttons and printed silkscreen icons opened the core apps (calendar, contacts, to-do, memo) from anywhere. | A bottom bar of exactly four destinations that never changes order or position across the whole product; no fifth item, no "more". |
| G5 · A learnable shorthand | Graffiti was a single-stroke alphabet: letters slightly simplified so the machine could recognise them, and the user met it halfway. | Gesture shortcuts shaped like the letter or symbol they trigger; a stroke diagram shown on first use; users can learn faster input over time. |
| G6 · Black tab title | Apps announced themselves with a small black, inverse-text title tab tucked into the top-left corner, content filling the rest. | Screen title = compact filled tab (inverse text) at top-left, not a full-width app bar; reclaim the rest of the header for content or one action. |

## Visual facts

- **Color:** reflective greenish-grey LCD (~`#A9B8A0`) with near-black pixels; later 4-grey and colour models kept the monochrome logic.
- **Type:** Palm's bitmap system fonts (standard, bold, large). Free: **Silkscreen** or **Pixelify Sans** for bitmap feel; **Atkinson Hyperlegible** for a legible modern take.
- **Form:** 1 px outlines, small rounded-rect buttons along the bottom, check boxes and pop-up triggers with tiny triangles.
- **Composition:** title tab top-left, content list full-width, command buttons in a single row at the bottom; nothing overlaps.

## Attitude

Jeff Hawkins treated the device as a paper replacement measured in seconds, and is remembered for carrying a pocket-sized wooden block to test the form before the product existed. The product's discipline was saying no. Borrow it whenever a product has to be used in a hurry, on a small surface, or alongside life rather than instead of it.

## Blends

- **Amplifies:** `dieter-rams`, `ambient-and-e-ink-ui`, `susan-kare`, economy, frequency over features, clarity at small sizes.
- **Productive tension with:** `flash-era-web`, expressive motion squeezed into a three-tap budget yields delightful micro-feedback rather than theatre.
- **Clashes with:** `bloomberg-terminal`, the terminal's "show everything" density contradicts Palm's "show the frequent 20%".

## Don't copy

- Palm logos and the Pilot/PalmPilot product forms, the Graffiti glyph set as drawn, Palm's application icons.
