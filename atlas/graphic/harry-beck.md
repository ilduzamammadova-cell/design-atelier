# Harry Beck (1902–1974)

**Essence:** Topology over topography — a map that shows how to get there, not where things are.

Henry C. Beck, an engineering draughtsman at the London Underground, submitted an unsolicited diagram that dropped geographic accuracy; after a cautious trial printing in 1933 the public embraced it, and he kept revising it for decades. It became the template for transit diagrams worldwide.

## Genes

| Gene | The idea | In UI / product terms |
|---|---|---|
| G1 · Diagram over geography | True distances and curves were discarded; only sequence, connections and interchanges kept | Any network UI (pipelines, service maps, user journeys, org charts) drawn as a schematic, not to scale; validate with "plan the route" tasks rather than accuracy checks |
| G2 · Octolinear grid | Lines restricted to horizontal, vertical and 45° | Diagram edges constrained to 0/45/90°, constant elbow radius (e.g. 8px), nodes snapped to an 8px grid |
| G3 · Enlarge the dense centre | The tangled central area was scaled up relative to the sparse outskirts | Focus + context: expand the selected or busiest cluster in graph views and compress the periphery, instead of uniform zoom |
| G4 · One colour per route, everywhere | Each line has a fixed colour that identifies it on map, signs and print | Persistent entity colours (per project, route or category) across map, list, chips and notifications; always paired with a name for colour-blind users |
| G5 · Distinct interchange glyph | Transfer stations get a special mark; ordinary stops are simple ticks | Two node types only: plain tick for a step, ring for a connection point; minimal legend |
| G6 · Ship, test, revise | The 1933 trial printing invited public reaction, and the diagram was refined for years | Release schematic views as a beta, measure task success and error rates, iterate visibly |

## Visual facts

- **Color:** saturated line colours (red, blue, green, yellow, black, brown) on white, with a single pale-blue river as the only geographic cue.
- **Type:** Edward Johnston's Underground sans, hand-lettered by Beck on the first artwork. Free: Railway Sans (open-source Johnston revival), Josefin Sans.
- **Form:** straight lines, 45° bends, ticks, interchange rings or diamonds.
- **Composition:** horizontal emphasis, balanced density, generous spacing between parallel lines.

## Attitude

Clarity for the rider over fidelity to the land: a passenger underground needs order and connections, not surface geography. Beck worked on it largely on his own initiative and fought to keep authorship.

## Blends

- **Amplifies:** `isotype`, `massimo-vignelli` — information made legible by abstraction.
- **Productive tension with:** `dada` — relabelling a rigid diagram with unexpected content is a classic artistic subversion; use it for playful brand maps of features or teams.
- **Clashes with:** `deconstructivist-type` — distortion and layering destroy the schematic's single job.

## Don't copy

The London Underground diagram in any version; the Underground roundel; Johnston's letterforms; the TfL line-colour set as a whole.
